# دليل تشغيل المشروع للفريق

هاد الدليل بيمشي معك خطوة خطوة من أول ما تنزّل المشروع لحد ما يشتغل عندك. الأوامر مكتوبة لـ **PowerShell على ويندوز**، وبتمشي نفسها تقريباً على ماك ولينكس.

> **قبل كل إشي:** ملفات `.env` فيها مفاتيح وكلمات سر. ما تحطها على GitHub، ما تبعتها بقروب عام، وما تعمللها commit. ملف `.gitignore` بيستثنيها، بس انتبه وإنت بتعمل `git add`.

---

## 1. البرامج اللي لازم تكون عندك

| البرنامج | ليش | كيف تتأكد إنه موجود |
|---|---|---|
| **Git** | تنزيل المشروع ومشاركة التعديلات | `git --version` |
| **uv** | بيدير Python 3.12 ومكتبات الـ backend لحاله، ما بتحتاج تنزّل Python لحاله | `uv --version` |
| **Node.js 22 أو أحدث** | الواجهة (React + Vite 8) | `node --version` |
| **ngrok** (اختياري) | بس إذا بدك تجرّب تيليجرام أو واتساب الحقيقيين | `ngrok version` |

تنزيل uv على ويندوز (مرة وحدة):

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

بعدها سكّر الـ PowerShell وافتحه من جديد. Node.js بتنزّله من nodejs.org (نسخة LTS).

git clone https://github.com/ayahabib/OrderFlow.git

## 3. ملفات الإعدادات (`.env`)

في ملفين، كل واحد بمكانه بالظبط:

| الملف | مكانه | فيه |
|---|---|---|
| إعدادات الـ backend | `backend\.env` | قاعدة البيانات، مفاتيح الذكاء الاصطناعي، أسرار القنوات |
| إعدادات الواجهة | `frontend\.env` | رابط Supabase العام ورابط الـ backend |

1. خذ الملفين من آية (رح تبعتهم بشكل خاص).
2. حطهم بالمكانين اللي فوق **بنفس الاسم بالظبط**: `.env` (بنقطة بالأول، وبدون `.txt` بالآخر). على ويندوز، تأكد إنه "File name extensions" مفعّل بالمستكشف عشان تشوف الامتداد الحقيقي.
3. اقرأ القسم 9 تحت: في قيم لازم تغيّرها أو تنتبه إلها.

إذا بدك تعمل ملفاتك من الصفر (مشروع Supabase خاص فيك مثلاً)، في نسخ فاضية: `.env.example` بجذر المشروع (للـ backend) و `frontend\.env.example`، وكل سطر فيها عليه شرح.

## 4. تشغيل الـ backend

افتح نافذة PowerShell وخليها مفتوحة:

```powershell
cd backend
```

```powershell
uv sync
```

(أول مرة بياخد دقيقة أو دقيقتين: بينزّل Python 3.12 والمكتبات.)

تأكد إنه قاعدة البيانات محدّثة:

```powershell
uv run python scripts/migrate.py --status
```

- إذا كل الملفات `applied`، تمام.
- إذا في ملفات `pending`، هاي تعديلات جديدة على قاعدة البيانات. **قاعدة البيانات مشتركة بيننا**، فاحكي بالقروب قبل ما تطبّقها، وواحد بس يطبّقها:

```powershell
uv run python scripts/migrate.py
```

شغّل السيرفر:

```powershell
uv run uvicorn app.main:app --reload
```

لازم تشوف `Uvicorn running on http://127.0.0.1:8000`. للتأكد افتح بالمتصفح http://localhost:8000/health ولازم يطلع `ok`.

## 5. تشغيل الواجهة

افتح نافذة PowerShell **تانية** (الأولى خليها شغّالة):

```powershell
cd frontend
```

```powershell
npm install
```

```powershell
npm run dev
```

افتح http://localhost:5173

> **مهم:** إذا Vite كتب إنه البورت 5173 مشغول واستخدم 5174، الـ backend رح يرفض الطلبات (CORS). يا بتسكّر البرنامج اللي ماخد 5173، يا بتضيف البورت الجديد لـ `CORS_ORIGINS` بملف `backend\.env` (القسم 9) وبتعيد تشغيل الـ backend.

## 6. أول تجربة

1. من صفحة الدخول اكبس **"ما عندك حساب؟ سجّل هون"** وعمل حساب بإيميلك. إذا وصلك إيميل تأكيد من Supabase، أكّده.
2. بعد الدخول بيطلب منك تعمل متجر: اكتب اسم ورقم وعملة.
3. **المنتجات والأسعار:** ارفع ملف Excel أو CSV. في ملف جاهز للتجربة: `eval\sample_inventory.csv`.
4. **الإعدادات ← مناطق التوصيل:** ضيف منطقة واحدة على الأقل، وإلا البوت رح يحوّل كل طلب لصاحب المتجر لما يوصل للعنوان.
5. **محاكي الشات:** احكي مع البوت كأنك زبون، مثلاً "بدي فستان احمر مقاس M".
6. شوف الطلب بصفحة **الطلبات**، والمحادثة بصفحة **المحادثات**.

## 7. تشغيل الـ tests

```powershell
cd backend
```

الـ tests السريعة (ما بتحكي مع قاعدة البيانات، بتخلص بثواني):

```powershell
uv run pytest -m "not db"
```

الـ tests الكاملة بتحكي مع قاعدة البيانات المشتركة. كل test بيشتغل جوّا transaction وبيرجّع كل إشي زي ما كان، فما بيخرب البيانات. بس هي **بطيئة** (حوالي 20 ثانية للـ test الواحد، لأنه السيرفر بطوكيو)، فشغّل بس ملف الـ test اللي إله علاقة بشغلك:

```powershell
uv run pytest tests/test_orders.py
```

الـ tests ما بتستدعي OpenAI أبداً (في LLM وهمي)، فما بتكلّف إشي.

## 8. أشياء اختيارية

### تيليجرام وواتساب الحقيقيين
بدهم رابط https عام للـ backend تبعك:

```powershell
ngrok http 8000
```

1. انسخ رابط الـ https وحطه بـ `PUBLIC_BASE_URL` بملف `backend\.env`، وأعد تشغيل الـ backend.
2. من **الإعدادات** اربط بوت تيليجرام.

> **تنسيق ضروري:** بوت تيليجرام ورقم واتساب الواحد بيبعتوا الرسائل لسيرفر **واحد بس**. إذا ربطت بوت آية من جهازك، رح توقف الرسائل عندها. استخدم بوت تيليجرام خاص فيك (من @BotFather)، وما تغيّر إعدادات واتساب بـ Meta بدون ما تحكي بالقروب.

### صفحات إدارة المنصة (الأدمن)
الأدمن بيشوف كل المتاجر، أرقام المنصة، وطلبات ربط واتساب. لتصير أدمن:

1. اعمل حساب جديد بإيميل تاني، **وما تعمل فيه متجر** (حساب الأدمن ما بيشوف صفحات المتجر).
2. من Supabase ← SQL Editor شغّل (حط إيميلك):

```sql
insert into platform_admins (user_id) select id from auth.users where email = 'admin@example.com';
```

3. سجّل دخول بهالحساب، بتفتح عندك صفحة `/admin`.

## 9. شو لازم تغيّر بملف `backend\.env` اللي وصلك

الملف جاي من جهاز آية. أغلب القيم بتضل متل ما هي، لأنه كلنا بنشتغل على **نفس قاعدة البيانات**. هاي القيم اللي لازم تنتبه إلها:

### لازم تغيّرها

| المتغيّر | شو تحط | ليش |
|---|---|---|
| `PUBLIC_BASE_URL` | `http://localhost:8000` | القيمة اللي وصلتك هي رابط ngrok تبع آية. إذا ضلّت هيك، الروابط اللي بيطلعها السيرفر بتروح لجهازها. غيّرها لرابط ngrok تبعك بس إذا بدك تجرّب تيليجرام أو واتساب (القسم 8). |

### غيّرها بس إذا احتجت

| المتغيّر | متى |
|---|---|
| `CORS_ORIGINS` | إذا الواجهة اشتغلت عندك على بورت غير 5173. مثال: `http://localhost:5173,http://localhost:5174` |
| `DASHBOARD_URL` | نفس الشي: رابط الواجهة اللي بيطلع بتنبيهات تيليجرام. الافتراضي `http://localhost:5173` |
| `OPENAI_API_KEY` / `LLM_API_KEY` | المفاتيح مشتركة وكل استدعاء بيكلّف. إذا عندك مفتاح خاص فيك حطه هون. حالياً موديل الشات على OpenRouter المجاني، ورصيد OpenAI خلصان، فميزات معلومات المتجر (اللي بتحتاج embeddings) رح تحوّل للتاجر لحد ما ينشحن الرصيد. |

### ما تغيّرها أبداً

| المتغيّر | ليش |
|---|---|
| `DATABASE_URL`، `SUPABASE_*` | إذا غيّرتها بتشتغل على قاعدة بيانات تانية فاضية. |
| `CHANNEL_ENCRYPTION_KEY` | التوكنات المحفوظة بقاعدة البيانات مشفّرة فيه. إذا تغيّر، ما حدا بيقدر يقرأها والقنوات بتوقف. |
| `WEB_CHAT_SECRET`، `TELEGRAM_WEBHOOK_SECRET` | جلسات المحاكي وروابط تيليجرام موقّعة فيهم. |
| `WHATSAPP_APP_SECRET`، `WHATSAPP_VERIFY_TOKEN` | مربوطين بتطبيق Meta تبع المنصة. |
| `TELEGRAM_NOTIFY_BOT_TOKEN` | بوت التنبيهات تبع المنصة، مشترك للكل. |

`frontend\.env` ما بتغيّر فيه إشي، إلا إذا شغّلت الـ backend على بورت غير 8000 (`VITE_API_BASE_URL`).

## 10. طريقة الشغل كفريق

1. قبل ما تبلّش أي إشي:

```powershell
git pull
```

2. اشتغل على فرع خاص فيك، مش على `main`:

```powershell
git checkout -b اسمك/اسم-الميزة
```

3. لما تخلص، ارفع الفرع واعمل Pull Request على GitHub، وخلي حدا تاني يراجعه.
4. **تعديلات قاعدة البيانات:** ملف SQL جديد بـ `supabase\migrations\` برقم بعد آخر رقم، تعديل واحد بكل ملف. احكي بالقروب قبل، عشان ما يعمل اتنين نفس الرقم، وعشان واحد بس يطبّقها.
5. اقرأ `CLAUDE.md` و `docs\` قبل ما تكتب كود: فيهم القواعد اللي ما بننكسرها، مثلاً إنه الذكاء الاصطناعي ما بيحسب أسعار، وكل query لازم يفلتر بـ `store_id`.

## 11. مشاكل شائعة

| المشكلة | الحل |
|---|---|
| الواجهة بتقول "ما قدرنا نوصل للسيرفر" | الـ backend مش شغّال، أو `VITE_API_BASE_URL` غلط، أو البورت مش 5173 (شوف CORS بالقسم 5). |
| `Python was not found` | ما تستخدم `python` مباشرة، استخدم دايماً `uv run python ...`. |
| الـ backend ما بيوصل لقاعدة البيانات | `DATABASE_URL` لازم يكون "Session pooler" (البورت 5432، والسيرفر `pooler.supabase.com`). |
| البوت بيحوّل كل إشي لصاحب المتجر | يا ما في مناطق توصيل، يا الموديل فشل (رصيد أو انقطاع)، يا الرد الآلي موقوف من الزر بالقائمة الجانبية. |
| غيّرت `.env` وما صار إشي | لازم تعيد تشغيل الـ backend بعد أي تعديل على `.env`. |
| `npm run dev` بيعطي خطأ عن Node | حدّث Node لـ 22 أو أحدث. |
